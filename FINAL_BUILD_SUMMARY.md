## 🐛 Troubleshooting

### Common User Issues

**"License key invalid"**
- Check for typos
- Verify key in LicenseKeyGenerator (option 2)
- Check if max activations reached
- Generate new key if needed

**"App won't start"**
- Add to antivirus exceptions
- Install VC++ Redistributable
- Check Windows version (need 7+)

**"Machine ID changed"**
- Hardware was upgraded
- Need to reactivate
- Deactivate old machine first

### Common Admin Issues

**"Database locked"**
- Close all LicenseKeyGenerator instances
- Check if CheatDabberTool is running
- Restart and try again

**"Can't generate key"**
- Check database permissions
- Verify data\ folder exists
- Run as administrator if needed
