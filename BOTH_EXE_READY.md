## 📝 Usage Instructions

### CheatDabberTool.exe (Users)

**First Launch**:
1. Double-click `CheatDabberTool.exe`
2. License activation window appears
3. Copy Machine ID
4. Contact admin: @BongCheatz_IT
5. Enter license key
6. Click "Activate"
7. Done! ✅

**Subsequent Launches**:
- Just double-click and use
- No activation needed again
- License persists permanently

---

### LicenseKeyGenerator.exe (Admin)

**Generate a License Key**:
1. Double-click `LicenseKeyGenerator.exe`
2. Select option `1` (Generate New License Key)
3. Choose validity:
   - `1` = 7 days (Trial)
   - `2` = 30 days
   - `3` = 90 days
   - `4` = 180 days
   - `5` = 365 days (1 year)
   - `6` = Lifetime
4. Enter max activations (usually `1`)
5. Add customer notes
6. **Copy generated key** → Send to customer

**View All Activations**:
1. Select option `3`
2. See all activated machines:
   - Machine ID
   - Computer name
   - License key used
   - Activation date
   - Expiration date

**Deactivate a Machine**:
1. Select option `4`
2. Choose machine from list
3. Confirm deactivation
4. Machine can now be reactivated
